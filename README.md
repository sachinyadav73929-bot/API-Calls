# Python API Data Fetcher

## Introduction
This project fetches user information
from an online API using Python.

## Technologies Used
- Python
- Requests Library
- REST API
- JSON

## Features
- Fetch user data
- Display name and email
- Display city
- Handle API errors

## API Used
https://jsonplaceholder.typicode.com/users

## How to Run
1. Install Python.
2. Install requests library.
3. Run python main.py.
